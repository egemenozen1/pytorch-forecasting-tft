# Third-party data and software

## UCI Air Quality dataset

This repository includes `data/AirQualityUCI.csv` and
`data/AirQualityUCI.xlsx` from:

> Vito, S. (2008). *Air Quality* [Dataset]. UCI Machine Learning Repository.
> https://doi.org/10.24432/C59K5F

UCI publishes this dataset under the
[Creative Commons Attribution 4.0 International license](https://creativecommons.org/licenses/by/4.0/).
The original dataset page is
<https://archive.ics.uci.edu/dataset/360/air+quality>.

## PyTorch Forecasting

The model in this project uses the `TemporalFusionTransformer`
implementation provided by
[PyTorch Forecasting](https://github.com/sktime/pytorch-forecasting), which is
distributed under the MIT License. This repository applies that library; it
does not claim to implement the TFT architecture from scratch.
